# Diário de Bordo

## Introdução
Foi desenvolvido individualmente um sistema administrativo para controle de estoque e vendas, aplicando HTML, CSS, JavaScript e PHP.

## Desenvolvimento
Primeiro foi definida a estrutura das sete entidades. Em seguida foram construídas a página inicial e as telas de cadastro. O JavaScript foi utilizado para interceptar o envio dos formulários e enviar os dados por `fetch()` aos arquivos PHP. O PHP recebe as requisições, valida os dados e devolve uma resposta JSON.

## Conclusão
O projeto atende à proposta do Momento I ao apresentar a estrutura das telas, formulários, navegação, comunicação JavaScript/PHP e planejamento das sete entidades, sem criação do banco de dados nesta etapa.
